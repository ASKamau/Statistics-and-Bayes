The distribution of one random variable

(12 points)

A lender’s records are organized by census tract. For a randomly drawn application, let \(X\) be the number of bank branches in the applicant’s tract and let \(Y\) equal 1 if the application is denied and 0 if it is approved.

Their joint probability distribution is:

  1. Fill in the margins. Sum across each row to get the distribution of \(X\), and down each column to get the distribution of \(Y\). Confirm that each set of margins sums to 1.

  2. Compute the expected number of branches. Write out all four terms.

\[ E(X) = \mu_X = \sum_{i} x_i\, P(X = x_i) = \rule{6em}{0.4pt} \]

  1. Compute \(E(X^2)\). Square the values; leave the probabilities alone.

\[ E(X^2) = \sum_{i} x_i^2\, P(X = x_i) = \rule{6em}{0.4pt} \]

  1. Compute the variance and the standard deviation.

\[ \text{var}(X) = E(X^2) - \left[E(X)\right]^2 = \rule{6em}{0.4pt} \qquad\qquad \sigma_X = \sqrt{\text{var}(X)} = \rule{5em}{0.4pt} \]

  1. \(Y\) takes only the values 0 and 1. Using the definition of expected value, show that \(E(Y) = P(Y = 1)\), then report \(E(Y)\) for this distribution.

\[ P(Y = 1 \mid X = 0) = \frac{P(X = 0,\, Y = 1)}{P(X = 0)} = \rule{5em}{0.4pt} \qquad\qquad P(Y = 1 \mid X = 3) = \rule{5em}{0.4pt} \]

  2. Compute \(\text{var}(Y)\) and \(\sigma_Y\), using the same shortcut as in 2(d). (For a 0/1 variable, \(Y^2 = Y\), so \(E(Y^2) = E(Y)\).)

  3. Compute \(E(XY) = \sum_x \sum_y x\,y\,P(X = x,\, Y = y)\).

Hint: every term with \(y = 0\) contributes zero, and so does the \(x = 0\) row. Three terms survive.

  1. Compute the covariance and the correlation.

\[ \text{cov}(X,Y) = E(XY) - \mu_X\mu_Y = \rule{5em}{0.4pt} \qquad\qquad \rho_{XY} = \frac{\text{cov}(X,Y)}{\sigma_X\,\sigma_Y} = \rule{5em}{0.4pt} \]
